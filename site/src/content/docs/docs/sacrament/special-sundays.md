Not every Sunday is a regular one. Choosing the right **Type** changes what Ward Desk asks you to plan.

## What you can do

- Mark a Sunday as a Fast Sunday, a conference, or a special program.
- Skip planning altogether for stake and general conference.

## The types

| Type | What happens |
|---|---|
| Regular | The usual program |
| **Fast Sunday** | Marked with a tag. New first Sundays start as Fast Sunday. |
| **Ward conference** | Marked with a tag. You still plan the meeting. |
| **Stake conference** | Presiding, conducting, hymns, prayers and the program are hidden, and the card says there is nothing to plan. |
| **General conference** | The same: there is no sacrament meeting to plan. |
| **Special program** | You can add a **Program title**, which shows on the card. |

## Fast Sunday

Fast and testimony meeting is almost always the first Sunday of the month, so planning a first Sunday starts it as Fast Sunday automatically. You can change the type if your ward is different. A saved meeting keeps whatever type you gave it.

## Stake and general conference

Choose **Stake conference** or **General conference** on the weekend it happens. The planning fields disappear. What you had entered is kept, so switching back to a regular Sunday restores it.

## Who can see this

The same as the rest of the sacrament plan: everyone with a role except called leaders can read it, and the bishopric edits it. See [Plan a Sunday](/docs/sacrament/plan-a-sunday/).
