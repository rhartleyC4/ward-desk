The **Requests** tab is a simple, kind way to ask. Nothing gets lost in a text thread, and everyone can see where things stand.

## What you can do

- (Bishopric) Ask a person to do something, with an optional due date.
- Say **Got it**, then **It's done** or **I can't do this**, with an optional note.
- Accept or decline a prayer or spiritual thought you were asked to give.
- (Ward leaders) Ask the bishopric for a calling change and follow it.

## What's on the page

| Card | Shows |
|---|---|
| **What would you like to do?** | Buttons to start a request (bishopric) or a calling request (ward leaders) |
| **Meeting assignments** | Prayers and spiritual thoughts you've been asked to give |
| **For you** | Requests waiting on you, and ones you finished lately |
| **Calling requests from leaders** | (Bishopric) new requests from leaders and ones received lately |
| **Your calling requests** | (Ward leaders) your calling requests and how far along each is |
| **You asked** | (Bishopric) requests you sent and what has happened |

The tab shows a count of what is waiting for you. If you have nothing yet, it says "When the bishopric asks you to do something, it shows here."

## Who can see this

A request can be read by the person who sent it and the person asked. A request between two bishopric members is bishopric business, so the whole bishopric can read it. Only the bishopric sends requests. Notifications name an office ("The bishop asked you to do something"), never a member or what was asked. See [Roles & privacy](/docs/roles-and-privacy/).
