Everything starts on the **Callings** section of the bishopric agenda (**Meetings**, then **Bishopric**).

## What you can do

- Add a calling to fill, and who it will release.
- Add one or more names to consider for it.
- Attach a name suggested by a leader to the right calling.
- Take a calling off the list if it is no longer needed.

## Add a calling to fill

1. Tap **Add a calling**, beside the **Callings to fill** heading.
2. Start typing the title. Titles from the ward's [calling list](/docs/settings/calling-list/) are suggested; you can type a new one and it is added to the list for next time.
3. If someone is being released, type their name in **Releasing (optional)**.
4. Tap **Add calling**. The new calling shows as its own card in the list.

## Add a name to consider

1. Find the calling's card.
2. Tap **Add a name** at the bottom of the card.
3. Type the name and tap **Add**.

You can add several names. Each shows as **Considering** until you approve one, and the card shows **To approve**.

## Add or change who is being released

If no one is listed, tap **Add who's being released** under the calling's title, type the name and tap **Save**. Once a name is accepted, a **Release *name* on** date appears at the foot of the card, next to the sustaining date, so you can say which Sunday the release is read. A calling that only releases someone (no one new) shows just the release date.

## Names suggested by leaders

Names from a leader's [calling request](/docs/callings/calling-requests/) come in two ways:

- When the request is for a calling, the suggested names are already under that calling with **Suggested by** the leader.
- A name suggested for a calling you are already filling appears under **New suggestions**. Choose **Attach to…** and pick the calling, or tap **Dismiss**.

## Take a calling off the list

Both are in the **⋯** menu at the top right of the calling's card, and both ask you to confirm.

- **No longer needed** removes it from the list because the need has gone away.
- **Remove calling** deletes the calling, its names and any open appointments for them. Use it only for a calling added by mistake.

## Who can see this

Only the bishopric. Ward leaders never see this section, even on a shared agenda.
