Once a name is approved and has met with a leader, the rest is recording what happened.

## What you can do

- Record that the person accepted.
- Set the Sunday the sustaining and the release are read.
- Mark the person set apart, which finishes the calling.
- For the ward clerk: see what to record in the Church's records.

## When they accept

1. In the calling's card, tap **Mark accepted** beside the name.
2. **Sustain *name* on** appears at the foot of the card, set to the coming Sunday. Change it if you need another date.
3. If someone is being released, the release date is set to the same Sunday. You can move it with **Release *name* on**, next to it.
4. The appointment is marked met, and the card shows **To sustain**.

If you marked the wrong person, choose **Undo accepted** from the **⋯** menu beside the name.

The calling stays on the list until the sustaining Sunday. From that Sunday it shows under **Sustainings today** and **Releases today** on the bishopric agenda, where you can move either date.

## When they are sustained

Once the sustaining date arrives, the name moves to **Waiting to be set apart** at the top of the callings section. It shows the sustain date and a **Set apart** button.

## Mark them set apart

1. Find the name under **Waiting to be set apart**.
2. Tap **Set apart**.

That finishes the calling: it leaves the list. If the calling came from a leader's request, the leader sees it as **Finished** and is notified. (A calling is finished when its name is set apart, not when the person accepts.)

## For the ward clerk

On Sunday afternoon from 1 PM, the clerk gets a notification: **Callings to record**, with how many callings were sustained and how many people released that day, so the Church's records can be updated. Ward Desk doesn't send anything to the Church's systems: it is a reminder only.

## Who can see this

The bishopric. The notification says only how many, never who. See [Roles & privacy](/docs/roles-and-privacy/).
