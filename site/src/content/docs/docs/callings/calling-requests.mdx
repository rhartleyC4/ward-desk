Ward leaders can ask for a calling change without seeing anything confidential. They send a request, and then just follow how far along it is.

## For a ward leader

### What you can do

- Ask for a calling to be filled, for someone to be released, or both.
- Suggest names.
- Follow your request: **Sent**, **Received**, **Being worked on**, **Finished**.

### Ask for a calling change

1. Open **Requests**.
2. Tap **Ask for a calling change**. If your organization is set on [Who can sign in](/docs/settings/who-can-sign-in/), it is picked for you.
3. **What do you need?** Choose one:
   - **A calling needs to be filled** (no one has it now)
   - **Release someone and call someone new**
   - **Release someone** (no one new is needed)
   - **Suggest a name** (for a calling the bishopric is already filling)
4. Tap **Next**. Type the calling. If it is on the ward's calling list, its organization is filled in; if not, choose **Which organization?**. If someone is being released, type **Who should be released?**.
5. Tap **Next**. Add names you'd suggest (optional, except for **Suggest a name**), a **Needed by** date if there is one, and **Anything else**.
6. Tap send. You see **Sent to the bishopric**.

### Follow it

Under **Your calling requests** each one shows its stage and a line of explanation:

You'll also get a notification when the bishopric starts on it and when it is finished. You never see names or decisions: only the bishopric does.

## For the bishopric

### What you can do

- See new requests the moment they are sent.
- Mark each one **received** so the leader knows you have it.
- Work on it like any other calling.

### How it arrives

- The callings in the request are **added to the callings list right away**, with a note of who asked for it, which organization, and when it is needed. Suggested names are already under the calling.
- The request is sent to the bishop or counselor whose assignment on the [standing schedule](/docs/settings/standing-schedule/) names that organization, or to the bishop when no one's does. They are notified.
- It shows under **Calling requests from leaders** on **Requests**, and as **New requests from leaders** at the top of the callings section.

### Mark it received

Tap the received button on the request (on **Requests** or on the agenda). The leader is told that the bishopric has it. Mark received once someone has seen it, not when it is finished. The leader's stage moves on as you work the calling: it becomes **Being worked on** once a name is being considered or a release is set, and **Finished** when the calling is set apart. See [Sustaining and setting apart](/docs/callings/sustaining-and-setting-apart/).

## Who can see this

A calling request can be read by the bishopric only. The leader who sent it sees only its stage, never names or decisions, and nothing else about callings. See [Roles & privacy](/docs/roles-and-privacy/).
