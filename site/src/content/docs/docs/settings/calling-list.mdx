The calling list is where the titles that the Calling box suggests come from.

## What you can do

- Add and rename callings.
- File each calling under an organization.
- Merge duplicates and tidy new titles.

<Screenshot name="settings-calling-list" device="phone" alt="The calling list grouped by organization." />

## Why it matters

When the bishopric types a title that isn't on the list, it is added for next time and shows up under an unreviewed group. Fix its spelling, file it under an organization, merge it into the right title or remove it. The organization is also what picks **Meets with** and routes a leader's calling request to the right counselor.

## Tidy the list

1. Open **Settings**, then **Calling list**.
2. Use **Find a calling** to search.
3. Edit a **Title** or pick its **Organization**.
4. To combine two, tap the merge icon and choose **Merge into**.
5. Tap the bin to remove a title.

Renaming a title also renames the open callings that use it. Filled callings keep the title they had.

## Add a calling

Under **Add a calling**, enter the **Title** and **Organization for the new calling**.

## Who can see this

Only admins can manage the list. The bishopric adds titles automatically as they type new ones.
