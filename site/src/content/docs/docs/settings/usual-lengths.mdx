## What you can do

- Set a normal length, in minutes, for each kind of interview.
- Know that a booking can still be changed one at a time.

<Screenshot name="settings-lengths" device="phone" alt="Usual lengths for each kind of interview." />

## Set a length

1. Open **Settings**, then **Usual lengths**.
2. For each kind (temple recommend, youth interview, extending a calling and so on), change the number of minutes, in 5-minute steps.

New appointments start at these lengths. Every kind starts at 10 minutes, which is also the minimum for a temple recommend interview. When you book, the secretary can still change a single appointment with the **−** and **+** buttons. Open times in the picker are stacked one after another, so lengthening or shortening a booking moves the open times around it.

## Who can see this

People with the bishopric role. The setting is shared by the whole bishopric.
