Ward Desk is open source (Apache-2.0). Any ward can run its own copy. This section is a short guide for the person who will do that.

:::caution[Please read this first]
Ward Desk is provided **as is**, with **no support**. Each ward that runs a copy is **responsible for its own copy and its own data**: where it is hosted, who has access, backups, and keeping it secure and up to date. The project and the hosted copy at warddesk.app have no access to your ward's data and can't help you recover it.

Ward Desk is an independent project. It is not affiliated with or endorsed by The Church of Jesus Christ of Latter-day Saints. Check the Church's guidance on third-party tools before using member information in any tool.
:::

## What you need

- A few free or low-cost accounts: **Supabase** (database, sign-in and background jobs), **Cloudflare** (hosting the app on Pages), **GitHub** (the code and automatic deploys), and **Resend** (sign-in emails). **Google Cloud** is optional, for "Sign in with Google".
- A domain name you control.
- A computer with Node.js, Docker and the command line. This is a technical job. Plan on a few hours, and ask a ward member who builds software if that is not you.
- Someone to be the ward's **admin**.

## A note on privacy

Your copy holds real member names. Keep it private to the ward, give roles only to people who need them, don't copy real data to a practice site, and never commit member information to the code. See [Roles & privacy](/docs/roles-and-privacy/).
